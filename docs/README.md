# Geometric_Lib

Geometric_Lib - это библиотека на языке Python для вычисления геометрических характеристик геометрических примитивов: квадрат, круг, прямоугольник, треугольник.
---
## 1. Общее описание решения
Geometric_Lib является математической библиотекой, в которой собраны пройстейшие геометрические вычисления.
Библиотека поддерживает данные геометрические фигуры:\
**1. Треугольник(triangle.py)**\
**2. Прямоугольник(rectangle.py)**\
**3. Круг(circle.py)**\
**4. Квадрат(square.py)**\
---
## 2. Описание функций
### 1. Треугольник
#### area(a,h)
**Формула:** $$S = a * h / 2$$\
**Принцип:** Передаем длину основания и высоты, функция возвращает площадь треугольника,с заданными значениями.\
**Параметры:**\
a(float) - длина основания треугольника\
h(float) - длина высоты треугольника\
**Возвращает:**\
(float) - площадь треугольника\
**Пример вызова:**\
```python copy
import triangle *
a = area(2, 3)
print(a) # Вывод: 3
```
#### perimeter(a,b,c)\
**Формула:** $$S = a + b + c$$\
**Принцип:** Передаем длины сторон треугольника, функция возвращает периметр треугольника,с заданными значениями.\
**Параметры:**\
a(float) - длина 1 стороны треугольника\
b(float) - длина 2 стороны треугольника\
c(float) - длина 3 стороны треугольника\
**Возвращает:**\
(float) - периметр треугольника\
**Пример вызова:**\
```python copy
import triangle *
per = perimeter(2, 3, 4)
print(per) # Вывод: 9
```

### 4. Круг
#### area(r)
**Формула:** $$S = pi * r * r$$\
**Принцип:** Передаем радиус круга, функция возвращает площадь круга, с заданным значением.\
**Параметры:**\
r(float) - длина радиуса круга\
**Возвращает:**\
(float) - площадь круга\
**Пример вызова:**\
```python copy
import circle*
a = area(2)
print(a) # Вывод: 12,56637
```
#### perimeter(r)
**Формула:** $$S = 2 * pi * r$$\ 
**Принцип:** Передаем радиус круга, функция возвращает периметр круга,с заданным значением.\
**Параметры:**\
r(float) - длина радиуса круга\
**Возвращает:**\
(float) - периметр круга\
**Пример вызова:**\
```python copy
import circle*
per = perimeter(3)
print(per) # Вывод: 18,84956
```
